# 合阳洽川湿地智慧管理平台 — UI设计规范

> **版本**: V1.0
> **来源**: 产品功能清单 + 设计参考稿
> **日期**: 2026-05-09

---

## 一、通用设计规范（所有页面强制遵守）

### 1.1 设计定位

资深智慧园区/湿地文旅/应急指挥中心数据可视化大屏 UI 设计，政府政务风格。严格按照《合阳洽川湿地智慧管理平台产品功能清单》规范。配色方案基于深青蓝系 **#00BFFF**，与原型保持一致。

### 1.2 整体风格

**高端政务科技风 + HUD 科幻未来风 + 极简商务风**
- 严禁：卡通、可爱元素、花哨装饰、粒子烟雾
- 定位：严肃专业，适配政府指挥中心领导、值班员使用

### 1.3 主色调体系（严格固定 — 深青蓝系 #00BFFF）

| 用途 | 色值 | 应用场景 |
|:-----|:-----|:---------|
| 主背景 | #0b1628 | 全局背景色 |
| 卡片面板底色 | rgba(10,20,40,0.5) | 所有卡片/面板/弹窗 |
| 卡片悬浮选中 | #1a2d4a | 卡片悬停/选中态 |
| **强调主色** | **#00BFFF** | **深青蓝，按钮/图标/强调文字/发光描边** |
| 强调主色悬浮 | #33CCFF | 深青蓝悬停态 |
| 一级火情红 | #FF3366 | 火警告警 |
| 二级疑似橙 | #ffa502 | 疑似告警 |
| 三级环境黄 | #e8c040 | 环境告警 |
| 四级提示灰 | #808080 | 提示类告警 |
| 在线成功绿 | #00CC99 | 设备在线/成功 |
| 文字主色 | #e8edf5 | 正文/标题 |
| 文字次要 | #8899bb | 次要信息/备注 |
| 边框/分割线 | rgba(0,191,255,0.15) | 卡片边框/分割线 |

### 1.4 视觉质感

- 所有模块、卡片、视频窗口、地图容器统一切角科技边框
- 带**青蓝色微光外发光描边**
- 半透明磨砂玻璃质感 + 细微网格底纹
- 模块分割工整对齐，排版规整，信息层级清晰

### 1.5 布局规范

- 适配 1920×1080 电脑端、3840×2160 4K 电视大屏
- 弹性栅格三栏/多栏布局
- 字体使用无衬线科技黑体（PingFang SC / Microsoft YaHei）
- 标题加粗带英文副标题
- 数据数字放大高亮
- 文字清晰无扭曲、无乱码、无错位重叠

### 1.6 地图规范

- 当前使用 **MapLibre GL** 开源免费引擎，后期可迁移至 高德/百度免费版
- 卫星/矢量底图切换，带发光轮廓图层
- 点位图标：
  - 绿色在线摄像头
  - 灰色离线设备
  - 无人机图标
  - 巡逻员定位图标
  - 红色闪烁未处理告警
  - 蓝色脉冲进行中工单
- 点击弹窗展示摘要信息
- 支持图层开关（设备/人员/告警/工单）

### 1.7 交互与动效

- 关键指标数字从 0 递增动画
- 超阈值、设备离线、一级告警红色边框闪烁
- 底部告警横向滚动条，悬停暂停
- 一级告警中央弹窗红光闪烁 + 紧急音效氛围
- 二级告警右侧滑入浮层
- 夜间模式深色自适应，19:00 自动切换

### 1.8 硬性禁止

- 禁止文字变形
- 禁止图表模糊
- 禁止元素错位
- 禁止画风杂乱
- 禁止写实风景乱入
- 禁止饱和度太高刺眼配色
- 禁止多余装饰元素

## 二、分页面设计规范

### 2.1 指挥中心首页总览大屏

**对应功能**: PC-01 至 PC-09

- **布局**: 左-中-右三栏弹性栅格，适配 4K 全屏
- **左栏**: GIS地图（MapLibre GL）主图层，设备/告警/工单/人员图层全开。摄像头绿灰点位、告警红点闪烁、工单蓝点脉冲、巡逻员图标带姓名标注。点击弹窗摘要，地图定位跳转
- **中栏**: 核心主视频大窗口，cover 铺满模式，叠加时间/地点信息栏
- **右栏**: 分模块卡片：环境监测面板 + 告警列表 + 关键指标（设备在线率、今日告警分级、工单完成率、运行天数）。在线率<80%红色闪烁，数字递增计数动画
- **底部**: 告警滚动条（等级色点+设备名+类型+时间），悬停暂停，点击定位
- **顶部**: 系统标题「合阳洽川湿地智慧管理平台」+ 英文副标题，右上角实时北京时间
- **系统运行状态指示灯**: 后端服务/流媒体/数据库/存储，异常红色闪烁
- **其他**: 值班交接班卡片入口、夜间模式切换控件

### 2.2 全景监控-视频墙9宫格

**对应功能**: PC-10 至 PC-19

- **布局**: 左侧设备树 + 右侧 3×3 九宫格视频窗口
- 视频窗口统一切角发光边框，右上角放大图标，顶部时间+点位水印
- 顶部 1/4/6/9 分屏切换控件，拖拽交换位置，双击全屏
- 悬浮工具栏：截图/录制/全屏/音频
- 加载占位图 + 离线时长 + 重试
- 底部居中「返回首页」按钮

### 2.3 单监控详情页

- 左侧：设备状态统计卡片 + 监控设备列表
- 中间：超大单路监控画面 + PTZ 控件
- 一键调取周边500米摄像头入口

### 2.4 环境监测数据大屏

**对应功能**: PC-56 至 PC-58

- 三栏：左信息面板 + 中GIS地图（MapLibre GL） + 右趋势图表
- 环境仪表盘：温度/湿度/风速/风向/雨量，超阈值红色闪烁
- 趋势图表：温度折线、降雨湿度组合、风速气压组合

### 2.5 智能告警列表

- 顶部筛选区（等级/状态/来源/时间/关键词）
- 告警列表表格，未处理红色置顶
- WebSocket 实时推送
- 告警统计卡片 + 7天趋势图

### 2.6 应急指挥工单管理

- 顶部筛选 + 批量操作
- 左侧工单地图（MapLibre GL）
- 中间工单卡片列表
- 右侧工单详情预览

### 2.7 无人机管理大屏

- 左栏：机场+无人机状态面板
- 中间：GIS地图+飞行轨迹
- 右栏：无人机直播+飞行参数
- 下方：任务记录+定时巡航+天气返航

## 三、迭代优化专用提示词

> 当生成结果不满意时使用：

1. 严格按照给定配色色值执行，不许私自改色调、改饱和度
2. 所有文字必须清晰简体中文，无乱码、无扭曲、无重叠、无错位
3. 模块严格对齐、等距排版，栅格布局规整，不随意留白、不杂乱排布
4. 保留原有 HUD 科技切角边框、青蓝色微光发光、磨砂玻璃质感不变
5. 只优化布局和细节，不更换整体画风、不改变三栏结构、不更改地图底图风格
6. 去掉多余粒子、光斑、花哨特效，保持政务指挥中心极简专业感
7. 严格参照《合阳洽川湿地功能清单》模块内容，不缺失功能卡片、不删减数据指标
