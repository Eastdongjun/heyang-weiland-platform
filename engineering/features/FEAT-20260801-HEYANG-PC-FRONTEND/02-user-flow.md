# 用户流与状态流

## 主路径

### 路径 1：值班员日常监控

```
登录(P01) → 导航页(P02) → GIS大屏(P03)
                              ├─ 看地图设备点位
                              ├─ 看 KPI 面板
                              └─ 告警弹窗 → 确认/误报
                                           └─ 自动建工单 → 工单调度(P13)
                                                          └─ 派发 → 等巡逻员接单
                                                                   └─ 处置反馈 → 审核归档
```

### 路径 2：管理员配置设备

```
登录(P01) → 导航页(P02) → 设备台账(P11)
                              ├─ 搜索筛选
                              ├─ 新增设备 → 表单(名称/编码/类型/IP/GPS选点)
                              ├─ 查看详情(P11-01)
                              └─ 编辑/删除
```

### 路径 3：领导视察

```
导航页(P02) → GIS大屏(P03) → 看设备在线率/告警统计
                           → 点地图看设备
                           → 切换到底部导航看各模块
                           → 数据统计(P07)
```

### 路径 4：应急响应

```
GIS大屏 → 一级告警弹窗 → 确认 → 自动建工单
                              → 应急管理(P09) → 查看工单
                              → 地图定位告警点
                              → 派发工单(P13-02)
                              → 跟踪处置(P13-01)
                              → 应急预案(P09-02)
```

## 异常路径

| 场景 | 入口 | 路径 |
|:-----|:-----|:-----|
| 登录失败 | P01 | 输错密码 → 红色提示 → 5 次失败锁定 → 15 分钟后重试 |
| Token 过期 | 任意页 | API 返回 401 → 跳转登录页 → 登录后回跳 |
| 地图加载失败 | P03 | 高德 JS 加载超时 → 显示"地图加载失败"+ 重试按钮 |
| 网络断开 | 任意页 | WebSocket 断开 → 连接状态指示器变红 → 自动重连 |
| 无权限访问 | 直接输 URL | 角色不匹配 → PE-04 无权限页 → 返回导航 |
| 数据为空 | 列表页 | API 返回空数组 → PE-02 空状态插图 |
| 页面不存在 | 输错 URL | 路由不匹配 → PE-05 404 页 → 返回首页 |

## 状态转换

### 告警状态机

```
[设备触发] → 未处理 ──确认──→ 已确认 ──(二级以上)→ 自动建工单
                 │
                 └──标记误报──→ 误报(选原因)
                 
不可逆：确认后不可回退为未处理
误报后不可再确认
```

### 工单状态机

```
待派发 ──派发──→ 待接单 ──接单──→ 处理中 ──提交──→ 待审核
                                                      ├──通过──→ 已完成
                                                      └──驳回──→ 处理中
已完成 ──归档──→ 已归档(只读)

待接单可改派 → 状态回退待派发
待派发超 30 分钟 → 列表显示"超时"标签
待接单超 15 分钟 → 列表显示"超时"标签
处理中超 2 小时 → 列表显示"超时"标签
```

### 设备状态

```
在线(心跳正常) ──心跳超 5 分钟──→ 离线(灰色图标)
离线 ──心跳恢复──→ 在线(绿色图标)
在线率 < 80% → KPI 红色闪烁
```
