## 约束

- 技术栈：Vue 3 + TypeScript + Vite + Element Plus + Tailwind CSS
- 地图：高德 JS API 2.0
- HTTP：Axios
- 实时通信：WebSocket
- 状态管理：Pinia
- 路由：Vue Router 4
- 包管理：pnpm
- 色彩：深青蓝系 #00BFFF，见附录 C
- 分辨率：1920×1080
- 夜间模式：默认深色主题
- 4 角色：ADMIN / OPERATOR / RANGER / MAINTAINER
- 部署：Nginx 静态文件，API 地址环境变量注入
- 后端 API 未开发，前端需 Mock 层

## 初始风险

1. 高德 JS API Key 需申请，免费额度需确认
2. 原型 HTML CSS 变量定义分散，需统一抽取为 Design Token
3. 后端 API 不存在，Mock 层设计需预留真实接口切换能力
4. 原型与实际 Vue 组件的设计还原度需逐页验证
