# UI 与交互规格

## 页面任务与信息层级

### P03 GIS 大屏（核心页面）

- **唯一任务**：让值班员一眼掌握湿地全局状态，快速发现异常
- **主动作**：查看地图设备 → 响应告警弹窗 → 切换底部导航
- **次动作**：查看 KPI 面板 → 点击设备弹窗 → 搜索定位
- **阅读顺序**：左上 KPI → 中间地图 → 右上设备状态 → 底部告警滚动条
- **信息密度**：高（值班员 8 小时盯屏，信息密度高可接受）

### P02 导航页

- **唯一任务**：按角色引导用户进入对应功能模块
- **主动作**：点击 10 个功能卡片之一
- **次动作**：切换角色 → 查看天气/时间 → 退出登录

### 后台管理页（P11-P20）

- **唯一任务**：管理员对单项数据做 CRUD
- **主动作**：搜索筛选 → 查看列表 → 新增/编辑
- **次动作**：导出 → 批量操作 → 查看详情
- **布局**：左侧边栏导航 + 右侧内容区（表格+搜索栏+分页）

## 设计系统

### 色彩 Token

```css
:root {
  /* 背景 */
  --bg-deep: #0A1628;        /* 全局背景 */
  --bg-card: #0F1D35;        /* 卡片/面板背景 */
  --bg-card2: #0A1C3C;       /* 次级卡片 */
  --bg-card-hover: #1A2D4A;  /* 卡片悬停 */

  /* 主色 */
  --accent: #00BFFF;         /* 按钮/图标/强调 */
  --accent-hover: #33CCFF;   /* 悬停 */
  --accent-dim: rgba(0,191,255,0.12);  /* 弱化 */
  --accent-glow: rgba(0,191,255,0.25); /* 发光 */

  /* 告警色 */
  --danger: #FF3366;         /* 一级告警 */
  --danger-glow: rgba(255,51,102,0.3);
  --warn: #FFA502;           /* 二级告警 */
  --warning-yellow: #E8C040;  /* 三级告警 */
  --info-gray: #808080;       /* 四级告警 */

  /* 状态色 */
  --success: #00CC99;        /* 在线/成功 */
  --cyan: #00E5CC;           /* 辅助色 */

  /* 文字 */
  --text: #E8EDF5;           /* 正文 */
  --text2: #8899BB;          /* 次要 */
  --text3: #606060;          /* 禁用 */

  /* 边框 */
  --border: rgba(0,191,255,0.15);
  --border-bright: rgba(0,191,255,0.3);
}
```

### 字号系统

| Token | 大小 | 用途 |
|:------|:-----|:-----|
| text-xs | 10px | 标签、辅助信息、KPI 标签 |
| text-sm | 12px | 面板标题、表格内容、次要文字 |
| text-base | 14px | 正文、列表、表单 |
| text-lg | 16px | 卡片标题 |
| text-xl | 18px | 页面标题 |
| text-2xl | 20px | 大标题 |
| text-3xl | 22px | KPI 数值 |
| text-4xl | 28px+ | 大屏专用标题 |

### 间距

- 最小间距：4px (gap in lists)
- 常规间距：8px (card gaps)
- 面板内边距：12px 14px
- 页面内边距：24px 28px
- 大屏间距：8px

### 圆角

- 按钮/标签：3px
- 卡片/面板：4px
- 弹窗：6px
- 全屏弹窗：8px

## 状态矩阵

| 状态 | 按钮 | 表格行 | 地图点位 |
|:-----|:-----|:-----|:---------|
| default | 主色背景+白色文字 | 白色文字 | - |
| hover | 亮度+10% | 背景 var(--accent-dim) | 缩放 1.2x |
| active/focus | 亮度-5% | 边框高亮 | 弹窗打开 |

## 响应式与可访问性

### 视口

- 主视口：1920×1080
- 大屏：3840×2160（后续适配，CSS 变量预备）
- 最小支持：1366×768（后台管理页）
- 地图区域：flex 弹性填充剩余空间

### 键盘

- Tab 键在表单字段间移动
- Enter 提交表单
- Escape 关闭弹窗/浮层
- 方向键在地图弹窗列表中切换

### 焦点

- 所有交互元素有可见焦点环（2px var(--accent)）
- 弹窗打开时焦点锁定在弹窗内

### 对比度

- 正文 #E8EDF5 对背景 #0A1628 = 13.5:1 ✅ AAA
- 次要文字 #8899BB 对背景 = 5.2:1 ✅ AA
- 禁用文字 #606060 对背景 = 3.1:1 ⚠️ 仅装饰性使用

### Reduced Motion

```css
@media (prefers-reduced-motion: reduce) {
  .alert-blink { animation: none; }
  .slide-in { animation-duration: 0.01ms; }
}
```
