# 需求规格

## 目标用户与场景

| 角色 | 场景 | 频率 | 目标 |
|:-----|:-----|:-----|:-----|
| 指挥中心值班员 | 8 小时轮班盯着大屏，收到告警立即响应 | 每日 | 快速发现火情、派发工单、跟踪处置 |
| 管理员 | 配置设备、用户、权限、系统参数 | 偶尔 | 维护系统基础数据 |
| 领导 | 视察时看大屏展示 | 不定期 | 了解系统运行状态 |
| 维保人员 | 查看设备台账和维保计划 | 每周 | 管理设备生命周期 |

| 事实 | 来源 |
|:-----|:-----|

| 假设 | 验证方式 |

## 业务规则与权限

| 规则 | 说明 |
|:-----|:-----|
| RBAC 菜单级权限 | ADMIN 全权限、OPERATOR 值班操作、RANGER 仅 App、MAINTAINER 设备+维保 |
| 导航入口控制 | 管理员入口（设备管理/系统配置）仅 ADMIN 可见 |
| 告警状态机 | 未处理→已确认或误报；确认后不可回退为未处理 |
| 工单状态机 | 待派发→待接单→处理中→待审核→已完成→已归档 |
| 告警与误报互斥 | 确认前可标记误报，确认后不可 |
| 一级告警不可跳过 | 必须人工确认，其他级别可自动收起 |
| 夜间模式自动切换 | 19:00 深色、07:00 恢复，可手动覆盖 |

## 异常与边界

| 场景 | 处理 |
|:-----|:-----|
| 地图加载失败 | 显示错误提示+重试按钮，降级为纯色背景 |
| API 请求超时 | 30 秒超时，Toast 提示"网络异常，请重试" |
| WebSocket 断开 | 自动重连（指数退避 1s/2s/4s/8s，最大 30s），状态栏显示连接指示器 |
| 告警列表为空 | 显示空状态插图+"暂无告警" |
| 设备全部离线 | KPI 面板设备在线率 0% 红色闪烁 |
| 登录 Token 过期 | 自动跳转登录页，保留当前 URL 用于登录后回跳 |
| 重复提交 | 按钮 loading 态防抖，3 秒内不可重复点击 |
| 大屏长时间运行 | 每 5 秒增量刷新数据，不整页 reload |
