# AGENTS.md

## 项目定位
- 项目：合阳湿地公园智慧管理平台
- 类型：大型企业项目，含需求、架构、PC端原型、移动端原型、技术文档
- 当前协作模式：`doc-design` 负责文档和架构，`ui-design` 负责原型页面与视觉一致性

## Profile 选择
- 需求说明、技术架构、开发文档、测试文档、部署说明：使用 `doc-design`
- `04-PC端原型/`、`05-移动端原型/` 下页面修改与审查：使用 `ui-design`
- 真正前端开发、后台实现、接口联动、权限与数据接入：使用 `dev-build`
- 不要混用 profile 做同一类工作

## 原型主题规则
- GIS / 视频 / 无人机 / 告警 / 统计 / 环境监测 / 应急：深色科技主题
- 用户管理 / 工单 / 排班 / 考勤 / 日志 / 角色 / 系统参数：浅色后台主题
- 禁止深浅主题乱串

## 原型执行规则
- 多项改动先输出理解摘要，经确认后再改
- 改布局时必须检查同系列页面的一致性
- 页面要适合截图进 Word，不能只顾浏览器里好看
- 未经确认，不动冻结或稳定页面

## 文档规则
- 文档按范围、角色、流程、模块、规则、风险组织
- 原型与文档描述必须互相对齐
- 技术架构和原型表达不能互相打架

## 开发实现规则
- `dev-build` 负责把已确认原型和已确认文档落成真实系统，不负责重新定义业务
- GIS / 视频 / 告警 / 统计等模块实现时，要同时说明页面、路由、接口、数据流和权限边界
- 小范围实现变更不得污染其他页面、其他主题或其他模块
- 开发交付时必须说明哪些页面、接口、状态、权限点已经检查
