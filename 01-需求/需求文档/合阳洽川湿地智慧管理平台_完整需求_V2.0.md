# 合阳洽川湿地智慧管理平台 — 完整需求说明 V2.0

> **版本**: V2.0  
> **日期**: 2026-05-21  
> **定位**: 湿地景区智慧安防与应急指挥平台  
> **性质**: ❌ 非生态监测系统

---

## 一、项目定位与边界

### 1.1 平台定位

**湿地景区智慧安防与应急指挥平台**，面向湿地景区的安全管控、防火防灾、巡逻调度和应急指挥。

### 1.2 范围边界

| 范畴 | 范围 |
|:---|:---|
| ✅ **负责** | 火灾防控·视频监控·无人机直播·巡逻工单闭环·智能告警·环境监测(仅天气)·设备管理·应急指挥·VR全景展示·遥感数据叠加·数据统计 |
| ❌ **不负责** | 水质监测·鸟类监测·人群密集监测·告警语音播报·无人机飞控(只看不控)·生态科研数据 |

### 1.3 用户角色

| 角色 | 终端 | 操作 | 权限 |
|:---|:---|:---|:---:|
| **值班员** OPERATOR | PC浏览器(1920×1080) | 看监控·处理告警·派工单 | 值班操作 |
| **领导** LEADER | PC/电视大屏(3840×2160只读) | 查看概览数据 | 只读 |
| **管理员** ADMIN | PC浏览器 | 管设备·管用户·配规则·看运维 | 全部 |
| **巡逻员** RANGER | 手机App(uni-app) | 接单·到场·拍照·上传 | 仅App |

## 六、核心业务闭环

```
传感器/AI检测 → 告警分级弹窗(无语音)
    ↓ 确认
自动建工单 → 推荐派发 → 巡逻员App接单
    ↓
到场处置 → 拍照上传 → 提交审核
    ↓
值班员审核 → 通过(归档) / 驳回(返回处理)
```
