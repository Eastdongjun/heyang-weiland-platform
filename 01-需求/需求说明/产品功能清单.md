# 第一部分：PC端（政府端）

**适用终端**：电脑浏览器(1920×1080) + 电视大屏(3840×2160)，同一套代码  
**适用角色**：指挥中心值班员、管理员、领导  
**交互方式**：鼠标键盘（大屏只读查看，不操作）

# 附录D：移动端离线策略

| 策略项 | 方案 |
|:-------|:------|
| 本地缓存 | SQLite，缓存上限200MB |
| 缓存清理 | LRU策略，超上限时自动清除最早7天前的数据 |
| 图片队列 | 拍照存本地文件系统→网络恢复后FIFO顺序上传+断点续传(HTTP Range) |
| 冲突策略 | **版本号检测**：每条数据带version字段。同步时服务端version > 本地→以服务端为准并提示用户。离线期间提交的处置数据若工单已被改派→保留供管理员人工判断 |
| 同步时机 | 网络恢复立即同步 + 每15分钟自动检查 + 下拉手动刷新 |
| 离线数据范围 | 已打开过的工单详情、个人档案、本区域摄像头列表(缩略图) |
| 位置缓存 | GPS每**60秒**存本地。**静止时(Activity Recognition检测)不触发GPS上报**，开始移动后恢复。有网实时上报，离线蓄积后批量上传 |
| 语音播报 | 预生成"您有新的任务"音频文件打包进App安装包，离线时播放本地文件 |
| 上传并发 | 最多同时3个上传任务，防止弱网下抢占带宽 |
